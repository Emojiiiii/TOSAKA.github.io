## 设计背景（Design Background）

### 设计灵感

本次设计从传统赌场与舞台纸牌魔术中提取视觉元素，并将其转化为具有功能表现的未来机械结构。

主要参考来源包括：

- **扑克牌：** 四种花色、牌面、牌背纹章、洗牌与切牌动作。
- **赌场筹码：** 筹码造型、环形纹路、色彩分层与筹码堆叠。
- **轮盘机械：** 旋转刻度、机械转轴与赌局结算的仪式感。
- **机械发牌器：** 卡牌输送轨道、排列结构、连续发牌运动。
- **舞台魔术：** 扑克牌消失、出现、悬浮、翻转与重组。
- **奢华装饰艺术：** 黑金金属、几何纹饰、酒红漆面及精密雕花。

### 设计目标

传统扑克主题武器容易停留在花色贴图与装饰层面，缺少武器行为与主题之间的联系。

因此，本次设计希望实现三个目标：

1. **主题结构化：** 将轮盘、发牌器和筹码转化为枪械的实际视觉构件。
2. **操作魔术化：** 让射击、换弹和检视具有不同的卡牌魔术表现。
3. **反馈系统化：** 建立筹码供弹、机械发牌与赌局结算之间一致的视觉逻辑。

最终形成一套能够通过外观、动作及视听反馈传达主题的神话级武器设计。

**核心设计理念：**将赌场中的扑克、筹码、轮盘与机械发牌器整合为一套完整的武器视觉系统。设计强调卡牌魔术与精密机械之间的结合，让枪械本身成为完成魔术表演的主体，而不是单纯依靠特效和外部装饰营造主题。

## 枪械外观设计（Weapon Appearance Design）

### 整体造型

以 LC10 原有的紧凑型冲锋枪轮廓为基础，保留枪口、机匣、握把、弹匣与枪托之间的主要比例关系。

在原枪轮廓上融入精密赌场机械结构，使武器整体呈现出一台微型自动发牌装置的视觉特征。

枪械结构主要分为三个层次：

- **外部装饰层：** 黑金护甲、酒红漆面、花色徽记与金属雕花。
- **内部机械层：** 发牌轨道、轮盘、齿轮、转轴与滑动组件。
- **动态能量层：** 红金色能量通路、筹码弹药与射击反馈。

造型强调横向延伸的修长感与中段机械核心的视觉对比，避免过多大型装饰影响武器辨识度。

### 枪械分区设计


| 枪械区域 | 设计内容 |
| ---- | ------------------------ |
| 枪口 | 黑桃轮廓与扇形金属构件结合，加入红色能量发光边缘 |
| 前部护木 | 镶嵌四种扑克牌花色，采用黑金金属面板与雕花结构 |
| 机匣上部 | 设置可视化卡牌输送轨道，显示牌面排列与滑动效果 |
| 机匣中央 | 配备旋转发牌转盘，作为枪械主要视觉核心 |
| 供弹区 | 展示筹码状能量弹药的输送过程 |
| 弹匣 | 采用压缩牌组与筹码储存结合的透明装饰结构 |
| 握把 | 使用酒红色防滑纹理与金色黑桃徽记 |
| 枪托 | 采用镂空金属骨架、梅花纹章与酒红装饰面板 |


### 材质与配色

**主色：曜石黑**

用于枪械主体框架和大型护甲，强调机械结构的重量感。

**辅助色：香槟金**

用于结构边框、齿轮、轮盘、金属雕花和装饰连接件，提升精密感与奢华气质。

**主题色：酒红色**

用于枪身局部漆面、握把、筹码与发光结构，建立赌场和魔术舞台的视觉联想。

**点缀色：象牙白**

主要用于扑克牌牌面与牌组纹理，增强不同结构之间的辨识度。

**动态发光：赤红与金色**

用于开火反馈、机关运动、卡牌幻术和命中效果。

整体采用高光金属与局部哑光漆面的对比，避免全枪持续发光导致机械细节难以识别。

## 核心机制设计（Core Mechanism）

本次设计不设置伴生生物或角色幻影，而是让枪械的赌场机关承担主要动态表现。

### 筹码弹药（Chip Ammunition）

**设计概念：将赌场筹码转化为武器弹药。**

普通枪械依靠弹药进行射击，而皇家牌局将弹药视觉化为一枚枚具有特殊纹路的筹码能量单元。

弹药设计特征：

- 弹药中部采用赌场筹码的环形纹路。
- 外圈分布黑、红、金三种识别色。
- 中心刻有扑克牌花色标识。
- 弹药经过供弹区时可见短暂的红金色光效。
- 发射后通过抽象能量轨迹表现筹码元素。

这里的筹码是一种主题化的虚构弹药，不要求完全按照现实圆形筹码制作武器内部结构。

它在视觉上需要与供弹系统相匹配，同时保持射击动作的流畅性。

### 发牌转盘（Dealer Mechanism）

**设计概念：每次射击都会驱动枪身上的发牌机关。**

在枪械中央设置一个类似赌场轮盘的旋转核心。

转盘外圈采用红黑交替刻度，中央镶嵌金属黑桃纹章。

转盘与上方的卡牌输送轨道形成一套完整的动态装置。

**运行表现：**

1. 玩家扣动扳机，触发枪械射击反馈。
2. 转盘沿固定方向进行小幅旋转。
3. 上方卡牌轨道同步滑动，模拟机械发牌。
4. 供弹区出现筹码能量流动。
5. 发光轨道短暂亮起，机关返回待机循环。

**设计目的：**

将射击动作与发牌动作建立直接联系，使武器每次开火都能够体现赌场主题。

### 连射联动（Continuous Firing）

LC10 属于高射速冲锋枪，因此机关表现需要考虑连续射击。

在连续开火时：

- 发牌轨道进行循环滑动。
- 中央轮盘保持连续旋转。
- 供弹窗口出现有节奏的筹码能量变化。
- 枪口形成连续但克制的红金色光效。
- 停止射击后，转盘逐渐减速并回归待机状态。

重点是让玩家感受到机关正在高速运作，而不是每次射击都让大型零件突然展开。

通过不同运动幅度与速度的组合，形成紧凑、精密且具有节奏感的反馈。

## 武器动画设计（Weapon Animation）

### 待机动画（Idle Animation）

**主题：赌局等待**

在玩家没有进行射击、换弹或检视操作时，枪械保持轻微的机械活动。

主要表现：

- 发牌转盘缓慢进行小角度运动。
- 枪身卡牌轨道偶尔调整牌面。
- 内部红金色能量沿结构间隙缓慢流动。
- 转盘中心黑桃纹章保持弱光状态。

待机动画应保持低频率与小幅度，避免干扰正常瞄准。

### 换弹动画（Reload Animation）

**主题：魔术换牌 — Sleight of Hand**

将传统换弹动作重新包装为一场扑克牌魔术表演。

**阶段一：旧牌退场**

玩家释放并取下旧弹匣。

弹匣脱离武器后，表面牌组结构短暂松动，边缘形成数张卡牌残影。

**阶段二：魔术洗牌**

玩家通过快速手腕动作，将卡牌残影展开为一小组悬浮扑克牌。

卡牌在手掌附近快速切牌、翻转，形成流畅的纸牌魔术效果。

**阶段三：筹码重组**

卡牌旋转并聚合，周围短暂出现数枚筹码能量单元。

这些视觉元素被金色机械边框约束，重新组成新的牌组弹匣。

**阶段四：重新入局**

玩家将新弹匣插入枪身。

中央发牌转盘快速旋转，机匣上方的牌面同步切换，最后停在黑桃 A 图案。

枪械恢复可射击状态。

**动画设计重点：**

换弹需要保留快速、清晰的操作节奏。魔术效果主要安排在弹匣离手、取出新弹匣和装填完成的视觉节点，不改变实际换弹判定与游戏数值。

### 检视动画（Weapon Inspection）

**主题：完美控牌 — The Perfect Deal**

检视动画着重表现武器拥有的卡牌魔术能力，以及枪械机械装置的精密程度。

**阶段一：展示机关**

玩家将 LC10 横向抬起。

中央轮盘开始转动，机匣上的卡牌输送轨道打开，内部机械组件进入展示状态。

**阶段二：抽牌魔术**

玩家通过另一只手从枪身侧面抽出一张扑克牌。

抽出的纸牌在手指之间翻转，随后分裂成数张具有金边的扑克牌。

**阶段三：空中洗牌**

玩家轻甩手腕，卡牌悬浮在武器周围。

卡牌经过切牌、翻转、重新排列后，形成一组扇形牌阵。

**阶段四：揭示底牌**

所有卡牌快速收拢，仅留一张背面朝向玩家的牌。

玩家翻开卡牌，显示一张黑桃 A。

与此同时，枪身中央的发牌转盘停止运转，转盘上的黑桃徽记与卡牌同步亮起。

**阶段五：魔术谢幕**

玩家轻弹卡牌。

卡牌瞬间消失，化作红金色细碎光点返回枪械。

机匣结构收拢，转盘恢复正常状态，检视结束。

**核心表现目标：**

检视动作需要呈现真正的纸牌魔术节奏——展示、迷惑、变化、揭晓与谢幕。

不依赖任何人物幻影或伴生角色，而是通过玩家手部动作、卡牌变化与机关互动完成表演。

## 视觉与音效反馈（Visual & Audio Feedback）

### 开火特效（Muzzle Flash）

枪口火焰以赤红和金色为主。

在常规枪口反馈基础上加入短暂的几何光片，呼应扑克牌与黑桃轮廓。

开火时枪口前端出现轻微的能量扩散，枪身机关与发光线路同步反馈。

### 命中特效（Hit Effect）

命中目标时，产生短暂的红金色能量粒子。

粒子外形可借鉴卡牌切角与金属筹码碎片，但不使用大量真实卡牌遮挡画面。

### 音效设计（Sound Design）

声音系统结合赌场与机械魔术两类素材。


| 触发行为 | 音效方向 |
| ---- | ------------------ |
| 待机 | 轻微机械齿轮与金属滑轨声 |
| 单次射击 | 枪械射击声叠加短促的机械发牌反馈 |
| 连续射击 | 规律的发牌机构循环声 |
| 换弹 | 洗牌、纸牌弹响、筹码碰撞与金属锁定声 |
| 检视 | 纸牌翻动、魔术式清脆音效、轮盘旋转声 |
| 击杀 | 筹码碰撞、轮盘停止与低频结算提示音 |


音效层级需要以枪械射击和关键操作提示为主，主题音效作为补充，避免过度装饰影响战斗反馈。
