## 1、设计背景

羽蛇神是中美洲文明中具有重要地位的神祇形象，结合了蛇与鸟类羽毛的视觉特征。本设计提取羽蛇、绿松石镶嵌、神庙雕刻以及古金色装饰等元素，构建一把兼具古代神秘感与生命力的皮肤。

与传统以华丽造型和发光特效为主的武器皮肤不同，本方案引入一条拥有独立行为与情绪表现的小羽蛇，使其成为枪械的一部分，同时也是玩家在战斗中的伙伴。

## 2、枪械外观设计


| 枪械部位 | 设计内容 |
| ---- | --------------------- |
| 枪口 | 抽象羽蛇头骨造型，内部嵌入翡翠色能量纹路 |
| 枪管 | 黑曜石色金属基底，搭配古金雕刻与绿松石镶嵌 |
| 机匣 | 半开放式神龛，为小羽蛇提供固定栖息位置 |
| 泵动护木 | 羽蛇鳞片纹理与阶梯状神庙纹样结合 |
| 装填区域 | 环形祭祀符文，随装填动作短暂点亮 |
| 枪托 | 层叠羽翼装甲，体现羽蛇神的神圣身份 |


整体轮廓保留 BY15 的长枪管、泵动护木及霰弹枪特征，避免过度装饰导致武器识别度下降。

材质以深色金属、古金、翡翠和绿松石为主，局部使用半透明能量材质，突出古代神器与现代枪械的融合。

## 3、小羽蛇角色设计

小羽蛇是整款皮肤最重要的差异化设计。

日常形态下，它拥有较大的翡翠色眼睛、短吻部、三片羽冠、修长的蛇身和羽毛状尾饰。性格活泼、好奇，偶尔表现出一点骄傲。

击杀进阶时，瞳孔收缩，羽冠展开，身体表面出现流动的金色纹样，身后浮现巨大的羽蛇神灵体。

两种形态共享相同的头部轮廓、羽冠和额头符号，保证角色的视觉一致性。

小蛇默认盘绕在机匣上方靠近玩家的一侧。它可以眨眼、呼吸、探头、摆动尾羽，并在指定动画中沿枪身移动。

## 4、特殊动作策划

### 4.1 泵动上膛 — Serpent's Rhythm

玩家向后拉动护木，小羽蛇受到震动后迅速抬头，羽冠竖起。护木到达后端时，小蛇收紧身体，翡翠能量沿枪身纹路流动。护木复位后，小蛇重新放松。

动画与原有泵动节奏同步，不增加实际操作时长。

### 4.2 装填动画 — Divine Offering

玩家将霰弹逐发推入装填口。小羽蛇探出头观察，每装入一发弹药，装填口周围的祭祀符文便短暂发光。

完成装填后，小蛇轻轻摆动尾羽，回到机匣上方。

小蛇主要承担视觉反馈，不直接改变弹药装填方式，确保装填逻辑与战斗可读性。

### 4.3 检视动画 — Bond of the Serpent

时长：约 5-7 秒，可被战斗操作打断

1. 苏醒： 玩家抬起枪械，小羽蛇睁开眼睛，缓慢伸展身体。
2. 互动： 小蛇从机匣爬到玩家手腕，轻轻蹭玩家的手指。
3. 觉醒： 小蛇突然抬头，眼睛释放金光，背后出现巨大的半透明羽蛇神灵体。
4. 回归： 灵体消散，小蛇恢复可爱姿态，重新盘回枪身，玩家恢复正常持枪状态。
